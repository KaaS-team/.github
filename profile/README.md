# KaaS

Software that ships its own work. We build open source tools for engineering teams, and the paid services around them.

**[kaas.team](https://kaas.team)**

## Open source

| Repo | What it does |
|---|---|
| [KaaS-factory](https://github.com/KaaS-team/KaaS-factory) | Turns tracker issues into reviewed, gated pull requests with the coding agents you already use. |
| [blueprint](https://github.com/KaaS-team/blueprint) | Engineering skills, agents, hooks and rules for coding agents. |
| [factory-plane](https://github.com/KaaS-team/factory-plane) | The cockpit web app for watching and steering runs (in development). |
| [factory-mcp](https://github.com/KaaS-team/factory-mcp) | An MCP server that will expose the factory to any agent (in development). |
| [factory-plugins](https://github.com/KaaS-team/factory-plugins) | Agent presets, runtimes and notifiers (in development). |
| [factory-install](https://github.com/KaaS-team/factory-install) | The curl and npm installers, waiting on the first binary release. |
| [homebrew-tap](https://github.com/KaaS-team/homebrew-tap) | The Homebrew tap; the formula comes with the first binary release. |

Everything is Apache-2.0 and signed off under the DCO.
