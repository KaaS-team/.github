# KaaS

Software that ships its own work. We build open source tools for engineering teams, and the paid services around them.

**[kaas.team](https://kaas.team)**

## Open source

| Repo | What it does |
|---|---|
| [factory](https://github.com/KaaS-team/factory) | Turns GitHub issues into verified pull requests with a swarm of coding agents. Install it, add `.factory` to any repo. |
| [blueprint](https://github.com/KaaS-team/blueprint) | Engineering skills, agents, hooks and rules for coding agents. |
| [factory-plane](https://github.com/KaaS-team/factory-plane) | The cockpit PWA for watching and steering runs. |
| [factory-mcp](https://github.com/KaaS-team/factory-mcp) | An MCP server that exposes the factory to any agent. |
| [factory-plugins](https://github.com/KaaS-team/factory-plugins) | Agent presets, runtimes and notifiers. |
| [factory-install](https://github.com/KaaS-team/factory-install) | The curl and npm installers. |
| [homebrew-tap](https://github.com/KaaS-team/homebrew-tap) | `brew install kaas-team/tap/factory`. |

Everything is Apache-2.0 and signed off under the DCO.
